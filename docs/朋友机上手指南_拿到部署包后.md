## 1. 包里有什么

解压后大致是这样（名字可能略有出入）：

```text
comfyUI-api-release/
├── app/                          ← API 程序
├── llm_workflow/                 ← 出图工作流（勿删）
├── scripts/                      ← 启动脚本
├── desktop/
│   ├── gateway/release/comfy-gateway.zip
│   └── studio/release/comfy-studio.zip
├── Frp/frp_0.71.0_windows_amd64/ ← frpc.exe + 配置
├── .env.example
├── requirements.txt
└── 本指南.md
```

**包里没有、需要你自己准备的：**

| 东西 | 做什么用 |
|------|----------|
| ComfyUI + 模型 + 自定义节点 | 真正用 GPU 出图 |
| Python 3.11 或 3.12 | 跑 API |
| 管理员发你的 **FRP token** | 连上云端隧道（私聊给你，不要发群） |

## 2. 还要下载什么、去哪下

### 2.1 Python（必装）

1. 打开：https://www.python.org/downloads/  
2. 下载 **Windows 64-bit** 安装包（3.11 或 3.12）  
3. 安装时务必勾选：**Add python.exe to PATH**  
4. 装完打开新的 PowerShell，执行：

```powershell
python --version
```

能看到 `3.11.x` / `3.12.x` 即可。

### 2.2 ComfyUI（必装）

任选一种你习惯的方式（二选一即可）：

- 官方仓库：https://github.com/comfyanonymous/ComfyUI  
- 或你平时用的整合包 / 启动器  

要求：

1. 本机能打开 ComfyUI 界面  
2. 用本包 `llm_workflow` 对应的模型与自定义节点，在 UI 里**能成功出一张图**  
3. 默认地址保持：`http://127.0.0.1:8188`（不要改成只给局域网乱绑公网）

> AMD 显卡（如 7900XT）：优先保证 ComfyUI 在你电脑上已经能跑通；Windows 上 AMD 环境因机而异，先解决出图再接 API。

### 2.3 本包已自带（一般不用另下）

- Comfy Gateway / Comfy Studio（zip）  
- `frpc.exe`（FRP 客户端）  
- API 源码与工作流

## 4. 配置什么、在哪里配

### 4.1 API 密钥 `.env`（必做）

1. 进入部署包根目录（有 `requirements.txt` 的那一层）  
2. 复制 `.env.example`，改名为 `.env`  
3. 用记事本打开 `.env`，至少改这一行：

```env
API_KEY=请改成一串很长的随机字符
```

可用 PowerShell 生成一串：

```powershell
-join ((48..57)+(65..90)+(97..122) | Get-Random -Count 32 | ForEach-Object {[char]$_})
```

把生成结果贴进 `API_KEY=`。  
**不要用别人发示例包里的旧 Key。**

其他项一般不用动。确认：

```env
COMFYUI_URL=http://127.0.0.1:8188
HOST=127.0.0.1
PORT=8000
```

可选：若管理员让你开 AI 润色，再按他给的填写 `POLISH_*`；没有就保持关闭/空即可。

### 4.2 FRP 客户端配置（必做）

打开：

```text
Frp\frp_0.71.0_windows_amd64\frpc.wzx.toml
```

（若没有 `frpc.wzx.toml`，用管理员给你的那份；**不要用**带 `18000` / `ollama` 的配置。）

确认/填写：

```toml
serverAddr = "111.229.166.216"
serverPort = 7000
auth.token = "管理员私聊给你的 token"

[[proxies]]
name = "qwen-image-api-wzx"
localIP = "127.0.0.1"
localPort = 8000
remotePort = 18001
```

要点：

- `remotePort` 必须是 **18001**（写错会连不上或冲突）  
- `auth.token` 与管理员一致  
- 本机 API 端口保持 **8000**

### 4.3（可选）一键脚本路径 `scripts\stack.local.json`

若你想用脚本一键启动：

1. 复制 `scripts\stack.local.example.json` → `scripts\stack.local.json`  
2. 按你电脑真实路径改，例如：

```json
{
  "comfyUiDir": "D:/ComfyUI",
  "comfyUiLaunch": "python main.py --listen 127.0.0.1 --port 8188",
  "frpcExe": "D:/comfyUI-api-release/Frp/frp_0.71.0_windows_amd64/frpc.exe",
  "frpcConfig": "D:/comfyUI-api-release/Frp/frp_0.71.0_windows_amd64/frpc.wzx.toml",
  "studioExe": "desktop/studio/release/win-unpacked/Comfy Studio.exe",
  "skipComfyUi": false,
  "skipFrpc": false,
  "skipApi": false,
  "skipStudio": false
}
```

路径改成你的盘符与目录。

## 5. 第一次安装 API 依赖

在部署包根目录打开 PowerShell：

```powershell
cd 你的\comfyUI-api-release路径
python -m venv .venv
.\.venv\Scripts\pip install -r requirements.txt
```

以后一般不用重装，除非换了电脑或删了 `.venv`。

## 6. 启动什么、怎么启动

每天用的顺序只有三样（或四样）：

```text
① ComfyUI  →  ② API  →  ③ frpc  →  ④ Studio（创作）
```

### 方式 A：推荐（Gateway 图形界面）

1. **先开 ComfyUI**（你平时怎么开就怎么开，等到能打开网页/`8188`）  
2. 打开 **Comfy Gateway.exe**  
3. 在 Gateway 里配置（首次）：  
   - 项目目录 = 本部署包根目录  
   - frpc.exe = `Frp\...\frpc.exe`  
   - frpc 配置 = `frpc.wzx.toml`  
   - 访问密钥 = 你 `.env` 里的 `API_KEY`  
4. 点启动 API、启动 FRP  
5. 打开 **Comfy Studio.exe** 开始用  

### 方式 B：一键脚本

ComfyUI 路径已写好 `stack.local.json` 后，在部署包根目录：

```powershell
.\scripts\start_stack.ps1
```

会按顺序尝试启动 ComfyUI → API → frpc → Studio。  
停止（默认不停 ComfyUI）：

```powershell
.\scripts\stop_stack.ps1
```

### 方式 C：全手动

```powershell
# 终端 1：先自己启动 ComfyUI

# 终端 2：API
cd 部署包根目录
.\scripts\start_api.ps1

# 终端 3：frpc
cd Frp\frp_0.71.0_windows_amd64
.\frpc.exe -c frpc.wzx.toml
```

## 7. 启动后怎么验收

### 7.1 本机

浏览器或 PowerShell：

```powershell
Invoke-RestMethod http://127.0.0.1:8000/health/ready
```

应看到类似：

```json
{"status":"ready","comfyui":"up", ...}
```

若 `comfyui` 不是 `up`：先把 ComfyUI 开好。

### 7.2 公网（说明 frpc 已通）

```powershell
Invoke-RestMethod https://qwen-image-2-1-wzx.sharex.team/health/ready
```

同样应为 `ready`。  
若本机 OK、公网 502：多半是 frpc 没开、token 错，或 `remotePort` 不是 `18001`。

## 8. Studio 怎么用

1. 打开 **Comfy Studio**  
2. **账号管理 / 登录**  
   - 首次：注册一个账号 → 到 **Gateway「用户」** 里审核通过  
   - 管理员自己：也可用 `.env` 的 `API_KEY` 作为服务端管理员（Gateway 访问密钥）  
3. 连接地址填：

```text
https://qwen-image-2-1-wzx.sharex.team
```

（不要末尾 `/`）  
4. 点「测试连接」，通过后即可：  
   - **开始创作**：文生图 / 改图 / 图生视频  
   - **任务队列 / 作品画廊**  
5. 手机或别的电脑要用：同样装 Studio，填同一个域名；用户需已审核通过。

> 出图算力永远在你这台电脑的 GPU 上。关机、休眠、断网后，公网域名会 502，属正常。

1. 开 ComfyUI

4. 不用时：关 Studio / 停 API+frpc；ComfyUI 可按需关

## 10. 常见问题

| 现象 | 处理 |
|------|------|
| `health/ready` 本机失败 | ComfyUI 没开，或不是 `127.0.0.1:8188` |
| 公网 502，本机正常 | frpc 没开；检查 token、`remotePort=18001` |
| Studio 连不上 / 401 | 域名填错，或 API Key / 账号未审核 |
| 提示缺节点 / 模型 | 先在 ComfyUI UI 用同一工作流跑通 |
| Python 找不到 | 重装并勾选 PATH，新开终端 |
| Gateway 找不到项目 | 项目目录选到含 `app`、`llm_workflow` 的根目录 |

## 11. 安全注意

- 不要把 ComfyUI `8188`、API `8000` 端口映射到路由器公网

- 生产使用建议 `.env` 里 `ENABLE_DOCS=false`
