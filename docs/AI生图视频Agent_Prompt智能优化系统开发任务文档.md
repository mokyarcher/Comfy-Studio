# AI 生图 / 视频生成 Agent 提示词智能优化系统开发设计文档

版本：V1.0

## 一、项目背景

当前 AI Agent 已实现：

-   用户输入自然语言需求
-   大模型生成提示词
-   调用 ComfyUI 工作流
-   完成图片/视频生成

但生成质量存在：

-   提示词普通化
-   缺少专业摄影语言
-   场景理解不足
-   人物、动物、机械结构容易错误
-   不同类型任务采用相同提示词策略

目标：

在现有生成链路中增加：

「AI 导演式 Prompt 优化层」

而不是重构整个生成系统。

# 四、Prompt 优化核心流程

## 1. 用户意图解析

不要直接扩写。

先提取：

-   主体
-   数量
-   动作
-   场景
-   风格
-   必须保留元素
-   禁止改变元素

示例：

输入：

一个女孩站在樱花树下

解析：

``` json
{
"subject":"女孩",
"scene":"樱花树下",
"action":"站立",
"important_elements":[
"女孩",
"樱花"
]
}
```

# 五、场景分类系统

根据任务自动选择规则。

支持：

## 人物肖像

重点：

-   面部稳定
-   五官一致
-   自然姿态
-   肢体结构

避免：

-   手指异常
-   五官漂移
-   身体比例错误

------------------------------------------------------------------------

## 动物

重点：

-   物种特征
-   自然运动
-   身体结构

避免：

-   肢体数量错误
-   不符合动物习性的动作

------------------------------------------------------------------------

## 汽车机械

重点：

-   结构稳定
-   运动方向
-   接地关系

避免：

-   零件变化
-   车轮错误

------------------------------------------------------------------------

## 产品广告

重点：

-   材质
-   光影
-   展示角度

避免：

-   产品变形
-   标志错误

------------------------------------------------------------------------

## 风景

重点：

-   空间层次
-   光线
-   环境运动

避免：

-   地形变化
-   场景漂移

------------------------------------------------------------------------

# 六、导演式 Prompt 生成

生成提示词必须包含：

## 主体描述

人物：

-   年龄感
-   服装
-   发型
-   姿态

动物：

-   品种
-   身体特征
-   行为方式

产品：

-   材质
-   结构
-   展示方式

------------------------------------------------------------------------

## 摄影语言

自动补充：

景别：

-   close-up
-   medium shot
-   full body

镜头：

-   static camera
-   tracking shot
-   dolly in
-   orbit shot

光线：

-   soft light
-   cinematic lighting
-   rim light

## 镜头怎么动

固定：

跟拍：

推进：

旋转：

------------------------------------------------------------------------

# 八、动作连续性检查

复杂动作拆分：

开始：

主体初始状态

进行：

主要动作过程

结束：

最终状态

避免：

-   同时多个复杂动作
-   动作跳跃
-   无因果变化

------------------------------------------------------------------------

# 九、Prompt Validator 审查模块

生成提示词后不要直接执行。

增加审核。

检查：

## 常识错误

例如：

错误：

汽车停在空中高速行驶

修改：

汽车在道路高速行驶

------------------------------------------------------------------------

## 动作冲突

错误：

人物静止站立，同时快速奔跑

处理：

删除冲突动作

------------------------------------------------------------------------

## 复杂度控制

错误：

人物跳舞、战斗、变身、跑步同时发生

处理：

拆分镜头

------------------------------------------------------------------------

# 十一、图生视频特殊规则

图生视频：

图片是视觉事实。

用户输入决定：

变化内容。

不要：

-   改变人物身份
-   修改服装
-   增加不存在物体

应该：

增加：

-   微动作
-   镜头变化
-   环境变化

例如：

人物照片：

推荐：

眨眼

轻微转头

头发摆动

镜头推进

不推荐：

突然转身

改变衣服

改变脸型

# 十四、开发 Agent 使用说明

将本文档提供给开发 AI Agent。

要求：

1.  先分析现有项目结构。
2.  找到 Prompt 生成位置。
3.  找到 ComfyUI 调用入口。
4.  不破坏已有功能。
5.  采用模块化新增方式。
6.  每次修改说明：
    -   修改文件
    -   修改原因
    -   测试方法
    -   对现有功能影响

不要一次性重构。

优先实现 Prompt Intelligence Layer。

# 十五、最终目标

让简单输入：

    一个女孩在森林里

经过优化后变成：

    A young woman standing in a misty ancient forest,
    wearing detailed clothing,
    natural posture,
    cinematic medium shot,
    soft morning light,
    realistic atmosphere,
    consistent facial features,
    stable body anatomy,
    professional photography style

目标：

让 AI 不只是生成提示词。

而是成为：

「AI 视频导演 + 摄影指导 + 质量审查系统」
